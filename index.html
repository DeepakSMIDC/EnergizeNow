Internship Technical Assignment

⏱ Completion time: 1 week

Assignment

You will be assigned one of the applications below. You will receive only a minimal description. Explore the problem yourself and decide what the application should contain.

Assigned Applications

01

HR Management

Build an application to manage employees and HR-related activities.

02

CRM

Build an application to manage customers and sales relationships.

03

Inventory Management

Build an application to manage products, stock, warehouses and inventory transactions.

04

Finance & Accounting

Build an application to manage financial transactions, income, expenses, invoices and accounts.

05

Complaints & Service Management

Build an application to manage customer complaints, service requests, assignments and resolution.

What Your Application Should Demonstrate

Explore the selected business domain and decide the appropriate features and workflow yourself. Your application should demonstrate, where applicable:

  • User-friendly UI
  • Appropriate data model and database design
  • Create, view, update and delete operations
  • Search, filtering and sorting
  • Appropriate business workflows and status handling
  • Form validation
  • Proper error handling
  • Meaningful dashboard or summary information
  • Basic authentication/user roles where relevant
  • Clean and maintainable code structure
  • API/backend integration where applicable
Important: You do not need to implement every possible feature of the selected application. Focus on a well-designed, working core application and explain what you would add if you had more time.

Rules & Freedom

  • You have 1 week to complete the assignment.
  • You may use any programming language, framework and database.
  • You may use AI tools such as ChatGPT, Claude, Gemini, Copilot, etc.
  • You may refer to Google, documentation, GitHub and existing applications.
  • Explore the requirements yourself. No detailed functional specification will be provided.
  • Focus on building something that is actually usable rather than only creating screens.
  • Be prepared to explain your decisions, architecture, data model and implementation during the interview.
What we want to see: how you understand an unfamiliar business problem, research it, make decisions, design the solution and build it independently.
